# زنجیر | Zanjir

اپلیکیشن پیام‌رسان مستقل اندروید با رابط Kotlin و Jetpack Compose و هدف استفاده از هستهٔ پیام‌رسان Gereh؛ بدون وابستگی به ورود، VPN یا سرویس‌های MLMVPN.

> وضعیت فعلی: فقط پوستهٔ اولیهٔ رابط کاربری در مخزن قرار می‌گیرد. هنوز هستهٔ شبکه/رمزنگاری متصل نشده و این نسخه پیام‌رسان عملیاتی یا APK انتشار نیست.

## مشخصات
- نام نمایشی: زنجیر
- شناسهٔ برنامه: `app.zanjir`
- پلتفرم فعلی: Android (معماری قابل گسترش)
- حداقل API: 24
- Kotlin + Jetpack Compose

## ساخت
Android Studio، JDK 17 و Android SDK 36 لازم است. پروژه را در Android Studio باز کرده و پس از Gradle Sync از مسیر Build > Build APK(s) خروجی بگیرید.

## نقشهٔ راه
1. تکمیل پوسته و هویت مستقل
2. ادغام هستهٔ Rust/Kotlin از `mlm-chat` و بررسی امضاهای API
3. ایجاد هویت و کارت/QR
4. افزودن مخاطب و گفت‌وگوی مستقیم
5. تاریخچهٔ امن، وضعیت پیام و اعلان‌ها
6. بررسی انتقال فایل و قابلیت‌های LAN/Bluetooth/P2P
7. آزمون امنیتی و انتشار

جزئیات فنی در `docs/` است. مجوزها و اعلان‌های کپی‌رایت upstream باید هنگام انتقال هر جزء حفظ شوند.
