# معماری زنجیر

```text
app/
  presentation/   رابط Compose
  data/           مخازن و آداپتورهای هسته
  domain/         مدل‌های هویت، مخاطب و پیام
core/             ماژول Android هستهٔ upstream (پس از بررسی و ادغام)
```

## مرزهای امنیتی
- رمزنگاری در لایهٔ رابط پیاده‌سازی نمی‌شود.
- کلید خصوصی در SharedPreferences یا فایل متنی ذخیره نمی‌شود.
- API هسته و چرخهٔ عمر `ChatNode` قبل از اتصال بررسی می‌شود.
- مجوزهای Bluetooth، اعلان و دستگاه‌های نزدیک فقط هنگام فعال‌سازی قابلیت درخواست می‌شوند.
- از ثبت کلیدها، محتوای پیام و داده‌های حساس در log خودداری شود.
